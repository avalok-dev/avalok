# Roadmap

Milestones 1–6 are complete: visualization/replay, Codex observation, repository intelligence, runtime adapters, polyglot/deployment analysis, and infrastructure intelligence.

## Recommended Milestone 7

Add opt-in live cloud and cluster adapters behind explicit credentials and least-privilege permission scopes. Project observed utilization and billing data onto the Milestone 6 provenance-aware resource metric model, while keeping static analysis independently useful. Include snapshot comparison so users can distinguish configured, observed, and drifted infrastructure without executing changes.

Hosted repository workflows, authentication, team collaboration, and remediation automation remain separate product decisions.
