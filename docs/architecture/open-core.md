# Open-core boundary

## Open-source core

- Schemas and normalization contracts
- Graph engine and layout interfaces
- Replay engine
- Local visualization and trace replay
- Repository scanners and telemetry adapters
- Plugin APIs
- Local storage

## Future cloud or commercial layer

- Authentication, organizations, and teams
- Hosted storage and production trace ingestion
- Large-scale analytics and alerting
- Collaboration and shared URLs
- Enterprise controls and governance
- Advanced optimization and AI-assisted analysis

Milestone 1 contains only the open-source visual foundation and local simulated fixtures. The UI has no dependency on accounts, plans, organizations, hosted storage, or other commercial concepts.
