## Rules for every draft

- **Do not post before the package is published.** Every command here assumes `npx avalok` works. Check with `npm view avalok dist-tags` and `npx avalok@latest --version` from a clean directory first.
- **Only claim what was run.** Anything in `[FILL: ...]` needs a real number, quote or link from you. Never invent a number, a user or a testimonial.
- **Use the product's own words.** "Detected", "observed", "inferred". Never "complete", "full visibility" or "understands your system".
- **Honest comparisons.** Name what other tools are good at. Check each comparison against the tool's current docs the day you post.
- **Be present.** Plan to answer every comment for the first day, and every issue within a day for the first two weeks.
